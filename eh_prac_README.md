### Feature Comparison

| Feature | Caesar Cipher | Playfair Cipher | Vernam Cipher |
|---|---|---|---|
| Definition | A simple substitution cipher in which each letter of the plaintext is replaced by a letter a fixed number of positions down the alphabet. | A manual symmetric encryption technique that encrypts pairs of letters (bigrams) instead of individual letters. | A symmetric encryption technique in which plaintext is combined with a key to produce ciphertext. |
| Type | Substitution cipher | Symmetric cipher | Symmetric cipher |
| Main principle | Letters are shifted by a fixed number of positions. | Letter pairs are encrypted according to rules using a 5×5 grid. | Plaintext is combined with a key, commonly using XOR in binary form. |
| Structure used | Alphabet | 5×5 matrix/grid | Key and plaintext |
| Encryption | Shift each plaintext character by the selected value. | Divide plaintext into pairs and apply the Playfair encryption rules. | Combine plaintext with the key to generate ciphertext. |
| Decryption | Reverse the character shift. | Apply the reverse Playfair operation. | Use the same key to recover the plaintext. |
| Example | With shift 3: A → D | Plaintext is processed in pairs. | Plaintext Key → Ciphertext |
| Important point | Works on individual characters. | Works on two characters at a time. | Security depends strongly on the key. |

# Practical 6

## Part 1: Open Burp Suite

**Step 1:** Open Kali Linux.

**Step 2:** Open the application menu and search for Burp Suite.

**Step 3:** Open Burp Suite.

**Step 4:** Select Temporary Project.

**Step 5:** Select Use Burp Defaults.

**Step 6:** Click Start Burp.

## Part 2: Configure Proxy

**Step 7:** In Burp Suite, go to:

`Proxy → Intercept`

**Step 8:** Make sure Intercept is OFF.

**Step 9:** Go to:

`Proxy → Settings`

and verify that the proxy listener is running on the required local port.

**Step 10:** Open the browser from Burp Suite using:

`Proxy → Intercept → Open Browser`

## Part 3: Open the Website

**Step 11:** In the Burp browser, enter the OWASP Juice Shop URL used in your lab.

**Step 12:** Press Enter.

**Step 13:** The Juice Shop website will open.

**Step 14:** Go to the Login page.

## Part 4: Capture HTTP Requests

**Step 15:** Return to Burp Suite.

**Step 16:** Go to:

`Proxy → HTTP history`

**Step 17:** You will see the HTTP requests generated by the browser.

**Step 18:** Select the request related to the Juice Shop login.

**Step 19:** Examine the request in the Request and Response sections.

## Part 5: Send Request to Repeater

**Step 20:** Right-click the selected HTTP request.

**Step 21:** Select:

`Send to Repeater`

**Step 22:** Open the Repeater tab.

**Step 23:** The selected HTTP request will appear in Repeater.

**Step 24:** Review the request parameters.

**Step 25:** Click Send to send the request to the server.

**Step 26:** Observe the HTTP response displayed on the right side.

## Part 6: Send Request to Intruder

**Step 27:** Go back to the request.

**Step 28:** Right-click the request.

**Step 29:** Select:

`Send to Intruder`

**Step 30:** Open the Intruder tab.

**Step 31:** Select the appropriate request parameter as the attack position.

**Step 32:** Go to the Positions section.

**Step 33:** Clear unnecessary automatically selected positions if required.

## Part 7: Configure Payloads

**Step 34:** Go to the Payloads tab.

**Step 35:** Select the payload type required for the experiment.

**Step 36:** Add the test values/payloads provided by your lab exercise.

**Step 37:** Check that the payload list is correctly loaded.

**Step 38:** Start the Intruder attack.

**Step 39:** Observe the results generated for each payload.

## Part 8: Analyze the Results

**Step 40:** Check the Status, Length, and Response of the requests.

**Step 41:** Compare the responses to identify differences.

**Step 42:** Open an interesting response and inspect its contents.

## VIVA

### Burp Suite

Burp Suite is a web application security testing tool used to inspect and test the communication between a web browser and a web server.

### Uses of Burp Suite

- Captures and analyzes HTTP/HTTPS requests and responses.
- Proxy allows us to intercept browser traffic.
- HTTP History helps view previously captured requests.
- Repeater allows us to resend and test requests.
- Intruder automates requests with different test inputs.
- Helps identify and analyze web application security vulnerabilities.
